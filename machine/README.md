# Machine entry point — Russian Emmy Noether edition

Start with `LANGUAGE_EDITION_INDEX.json`. It identifies the exact Russian
language/script key, current lane head, editable sources, German/project
authority relation, deterministic reader, decision ledger, QA evidence, DOI
lineage, and the protocol for extending the edition.

“Canonical lane head” means canonical **for this edition’s Russian lane**. It
does not mean a prescriptive canon of Russian mathematical language, native
certification, or a critical edition. Versioned translation units are lineage
witnesses; generated PDFs are deterministic outputs, not independent textual
witnesses.

Source comments using `noether-corpus://corpus/…` are portable logical
locators. Resolve the suffix through the index and evidence package, not by
reconstructing a private workstation path.
